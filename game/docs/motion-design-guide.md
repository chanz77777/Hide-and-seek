# Motion Design Guide — モーション設計と192の技の体系

本書は [Motion Prompt](https://showheyohtaki.github.io/motion-prompt/)（AIおよびクリエイティブディレクションのためのモーションライブラリ・全192技）の設計思想と技法を体系化し、本ゲーム「お絵描きかくれんぼ」をはじめとするWeb/Canvas/Three.jsフロントエンド実装へ応用するためのリファレンスです。

---

## 1. 192の技の全体構造（6大パック）

Motion Prompt は、アニメーション・映像・UI・Web演出を次の6パック（各24〜48技、計192技）に分類しています：

| パック | 対象領域 | 主なカテゴリと技の例 |
| :--- | :--- | :--- |
| **1. Motion** | モーショングラフィックス | **登場・文字**: ポップアップ、タイプライター、マスクスライド<br>**質感・味付け**: バウンス、オーバーシュート、慣性、伸縮（Squash & Stretch）<br>**見せ場・転換**: スピードライン、爆発、スプリット、モーフィング |
| **2. Camera** | カメラワークと構図 | **カメラ動作**: パン、チルト、ドリーイン/アウト、トラッキング、スパイラル<br>**時間・演出**: ヒットストップ（Impact Freeze）、スローモーション、タイムラプス<br>**切り替え**: マッチカット、ウィップパン（高速パン）、ディゾルブ |
| **3. UI** | マイクロインタラクション | **状態変化**: ホバーリフト、リップル、スケールタップ、シェイクエラー<br>**進行・ローディング**: プログレスバー、スケルトンスクリーン、パルス<br>**画面遷移**: シートスライド、モーダルポップ、共有要素トランジション |
| **4. Web / LP** | スクロール・インタラクティブ | **スクロール連動**: パララックス、ピン留め、プログレスインジケーター<br>**ヒーロー・背景**: リキッドウェーブ、グラデーションシフト、パーティクルネット<br>**視線誘導**: スポットライト、マグネットカーソル、キネティックタイポ |
| **5. Photo** | 光・陰影・色調表現 | **ライティング**: レンズフレア、ボケ、リムライト、ドラマチックシャドウ<br>**ポストプロセス**: ブルーム、色収差（Chromatic Aberration）、フィルムグレイン |
| **6. Effect / Anime** | アニメ的・ゲーム的エフェクト | **衝撃・ヒット**: 稲妻（Lightning）、集中線（Speed Lines）、衝撃波（Shockwave）<br>**軌跡・残像**: オーラトレイル、スモークリング、アフターイメージ<br>**バースト・消滅**: スパークル（十文字星）、パーティクル飛散、ディスインテグレーション |

## 2. コア原則と数理（時刻 $t$ による決定論的モーション）

Motion Prompt の見本実装はすべて「時刻 $t$ だけで状態が一意に決まる純粋関数」で記述されています。

### ① イージング（Easing）の使い分け
- **Ease-Out（急発進・なだらかに停止）**: 登場やヒット直後の余韻に最適。
  $$f(t) = 1 - (1 - t)^3$$
- **Ease-In（ゆっくり加速・急激に抜ける）**: 画面外への吹っ飛び、退場に最適。
  $$f(t) = t^3$$
- **Elastic / Overshoot（行き過ぎて戻る）**: 手応え、小気味よいバウンド。
  $$f(t) = \sin(t \cdot \pi \cdot (0.2 + 2.5 t^3)) \cdot \text{pow}(1 - t, 2.2) + 1$$

### ② タメとツメ（Anticipation & Release）
- アニメーションの原則「予備動作（Anticipation）」。
- 強く放つ前に一瞬縮む、あるいは時間が止まることで、その後の爆発的なスピードが何倍にも感じられる。

### ③ スタッガー（Stagger / 時間差の美学）
- すべての要素（文字、エフェクト、カメラ、SE、UI）を同時に動かすと散漫になる。
- **直撃（閃光・雷・停止）** $\rightarrow$ **吹っ飛び（軌跡）** $\rightarrow$ **場外炸裂（バースト星）** $\rightarrow$ **UIカットイン** と、50〜200ms単位で波状にずらすことで圧倒的な爽快感を生む。

## 3. 本ゲームへの具体的適用（KOフィニッシュ演出の強化）

本ゲームの「見つけた！とどめの吹っ飛ばし演出」には、Motion Prompt から以下の技を融合しています：

1. **#041 Impact Freeze（ヒットストップ）**: 直撃の瞬間、0.85秒間被弾キャラを停止・小刻み振動。
2. **#018 Lightning Strike & Speed Lines（雷撃と集中線）**: 被弾点を中心に放射状集中線とジグザグ稲妻。
3. **#072 Smoke Trail / Aura（煙トレイル）**: 吹っ飛ぶマネキンの足跡に、多重の拡大スモークリングを生成。
4. **#089 Screen Shake & Burst Sparkle（画面揺れと場外星バースト）**: 画面端突破時に巨大な十文字発光星（✨）が炸裂。
5. **#105 Staggered Cut-in（時間差カットイン）**: バーストの瞬間に「見つけた！」HUDを飛び出させ、視線と感情のピークを一致させる。
