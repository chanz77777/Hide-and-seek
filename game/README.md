# お絵描きかくれんぼ（ステップ 1: 隠れる人 / ステップ 2: 見つける人）

`public/index.html` をブラウザで開くだけで、ローカル対戦（別タブ・1 台で交代）が動きます（Three.js は `public/vendor/` に同梱）。
オンライン対戦は `npm run dev`（http://localhost:3000）か Vercel で動きます。デプロイ手順は `DEPLOY.md`、通信仕様は `docs/online-protocol.md`。

## 構成

| ファイル | 役割 |
|---|---|
| `public/index.html` | 画面の骨組み（HUD・オーバーレイ・スタイル） |
| `public/js/floor.js` | 床テクスチャ生成。絵文字を乱数シードで敷き詰める `Floor.generate({seed})` |
| `public/js/paint.js` | マネキン生成とテクスチャペイント `Paint.createMannequin()` / `Paint.createPainter()` |
| `public/js/link.js` | 同じ PC の別タブ同士の連携（BroadcastChannel） |
| `public/js/online.js` | オンライン対戦（部屋・ロビー・ポーリング・ラウンド進行） |
| `api/`・`lib/` | Vercel Functions（部屋の状態は Upstash Redis、画像は Vercel Blob） |
| `dev/` | ローカル開発サーバー（`npm run dev`）と API テスト（`npm test`） |
| `public/js/main.js` | 移動・回転・カメラ・ミニマップ・タイマー・爆撃と命中判定・画面遷移 |
| `public/vendor/three.min.js` | Three.js r158（UMD） |

## 床の絵

タイトル画面で「画像を取り込む」（既定）か「自動生成」（絵文字を敷き詰める。床の番号で再現可）を選ぶ。画像は縦横比を問わず、床の比率（16:12 = 4:3）に中央で切り抜いて使う。ファイル選択のほか、タイトル画面へのドラッグ＆ドロップでも取り込める。横幅 3000 px 以上の画像は 4096×3072、それ未満は 2048×1536 のテクスチャになる。

## 遊び方

- **2 タブで遊ぶ**: タブ A のタイトルで「見つける人になる」を押して待機。タブ B で床を選んで「隠れる」。B の準備が終わると（準備完了 or 90 秒）、A に床・体の塗り・位置が送られ、捜索が始まる。爆撃と結果は B にも届く。
- **1 台で交代**: 隠れる人の準備完了画面で「この画面で見つける人に交代」→「見つける人、準備 OK」。
- **見つけるターンは全員同じ画面**: 隠れる人も見つける人と同じ真上の画面を観戦し、見つける人の照準（白い輪）の動き、爆風、「〇〇をみつけた！」「みつかってしまった…」などのカットインが全員に表示される。観戦中はクリックしても爆撃されない。
- **見つける人**: 真上の固定視点で床全体を見て、怪しい場所をクリックして爆撃。爆弾は隠れる人数 × 3 発、制限時間 60 秒。制限時間の 1/3 を過ぎると人の影・ツヤが徐々に出て、終了時に 100% になる。

## 操作

- `W A S D` / 矢印: スライド移動、`Q` `E`: 回転
- `Space`: 移動 ⇄ ペイント（停止中のみ）
- ペイント中: 左ドラッグで塗る、右ドラッグ（または Shift+左ドラッグ）で視点回転、ホイールでズーム、`Ctrl+Z` で元に戻す
- ペイント中の道具: ブラシ / パーツ塗り / スポイト（床や体の色を拾う。`Alt`+クリックでも可）/ 一括擬態（体の各点の真下にある床の色で塗る。`CAMO_BLOCK` 四方のモザイクにし、彩度 `CAMO_SAT`・白寄せ `CAMO_LIGHT` で少しずらす）
- ペイント中は右下に「見つける人の見え方」（真上・同じ縮尺）の小窓が出る。クリックで 1 倍 → 2 倍 → 4 倍に拡大
- `Enter` または「準備完了」で終了 → 「確認ビュー」で見つける人の視点（真上）を確認できる
- `Ctrl+V`: プレイ中に確認ビューを切り替え（開発用）

## 開発用 URL フラグ

- `index.html#start` … タイトルを飛ばして移動画面から開始
- `index.html#start,paint` … ペイントモードで開始
- `index.html#start,paint,demo` … 合成ポインタイベントで一筆描く（ペイントの動作確認）
- `index.html#start,top` … 確認ビュー（真上）を直接開く
- `...,camo` を付けると開始直後に一括擬態を実行、`...,pip4` で小窓を 4 倍にして開く
- `index.html#seek` … 見つける人として待機画面を開く
- `index.html#start,hotseat` … 隠れる → すぐ交代して捜索を開始
- 自動テスト用に `window.kakurenbo`（状態の取得、床座標 → 画面座標の変換、準備完了、演出の一時停止とコマ送り）を公開している
- `index.html#imgtest` … 横長のテスト画像を取り込んだ状態で開く（切り抜きの確認）
- `...,shade` を付けると人の影・ツヤを 100% にした状態で開く（確認ビューのスライダーでも変更可）

## 人の影・ツヤ

人は既定で「影・ツヤなし」（床の絵と同じ平坦な描画。塗った色がそのまま出る）。`setShading(k)`（`js/main.js`）で 0〜1 に変えられ、見つける人のターンでは制限時間が迫るにつれて 0 → 1 に上げる予定。床もライティングなしで描くため、塗った色は床の色と完全に一致する。

## 主なパラメータ（`js/main.js` 冒頭）

`WORLD_W / WORLD_H`（床 16 × 12 unit）、`PLAYER_SCALE`（人の大きさ 0.25 = 寝転んだ長さ約 0.5 unit）、`PREP_SECONDS`（90 秒）、`SEEK_SECONDS`（60 秒）、`BOMBS`（隠れる人数 × 3）、`BOMB_RADIUS`（爆風半径 0.2 unit）、`SHADE_START`（影・ツヤを出し始める時点 1/3）、`MOVE_SPEED`（1.2 unit/秒）、`ROT_SPEED`（90°/秒）
