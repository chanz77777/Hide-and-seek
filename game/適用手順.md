# Vercel Blob 修正の適用手順

## 何を直すか
Vercel Blob をプロジェクトにつなぐと、今は OIDC 方式で認証され、環境変数は `BLOB_STORE_ID` などになる（`BLOB_READ_WRITE_TOKEN` は入らない）。
旧コードは `BLOB_READ_WRITE_TOKEN` しか見ていなかったため、Vercel 上でローカル保存に切り替わり `ENOENT ... mkdir '/var/task/.../dev'` で失敗していた。

## 入っているファイル
| ファイル | 変更内容 |
|---|---|
| `lib/blob.js` | `BLOB_STORE_ID` か `BLOB_READ_WRITE_TOKEN` があれば Blob を使う。認証は SDK に任せる。Vercel 上で未接続・保存失敗のときは分かりやすいエラーを返す |
| `package.json` | `@vercel/blob` を 1.1.1 → 2.8.0（OIDC 対応）。`engines.node` を `>=20` に |
| `package-lock.json` | 上に合わせて作り直したもの |

## 手順
1. この 3 ファイルを、デプロイしているリポジトリの同じ場所に上書きコピーする（`package.json` があるフォルダが基準）。
2. Vercel の Settings → Environment Variables に `BLOB_STORE_ID` があり、Production にチェックが入っているか確認する。
3. Blob ストアが **Public** で作られているか確認する（Private だと保存に失敗する）。
4. コミットして push する（自動で再デプロイされる）。
5. 床を「自動生成」してエラーが出ないことを確認する。

## ローカル開発について
`@vercel/blob` 2.x は Node 20 以上が必要。Node 18 のままでも `npm run dev` は Blob を使わないので動くが、`npm install` で警告が出る。
